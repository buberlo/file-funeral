# File Funeral

> Give old files a dignified burial before you delete them.

A local tool scans folders for abandoned files, assigns each a short life story from metadata, and requires a final epitaph before deletion. It keeps a mausoleum log so nothing disappears without a goodbye.

## Features
- Folder scan for stale files
- Metadata life story generator
- Final epitaph prompt before deletion
- Mausoleum log with restore tombstone

## Stack
- Electron
- Python
- SQLite

## Getting started
```
npm install && npm start
```
